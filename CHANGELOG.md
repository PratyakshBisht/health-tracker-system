# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/en/spec/v2.0.0.html).

## [1.0.0] - 2025-01-04

### Added
- Initial project setup with monorepo structure
- Backend (Express.js + TypeScript + PostgreSQL + Prisma)
- Frontend (React + TypeScript + Vite + Tailwind CSS)
- Authentication module with JWT and refresh tokens
- User registration and login endpoints
- Database schema and migrations
- Comprehensive configuration (ESLint, Prettier, TypeScript)
- Docker and Docker Compose setup
- GitHub Actions CI/CD workflow
- Husky pre-commit hooks
- Project documentation

### Security
- Password hashing with bcrypt
- JWT token-based authentication
- CORS protection
- Environment-based configuration
- Helmet.js for HTTP headers
- Rate limiting
